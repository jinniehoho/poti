# Build 8 베타 테스트 후속 목록

Build 8에서는 80종 식물 카탈로그, 한국어·영어·독일어 식물명/검색 데이터,
식물 등록 검색 UI, 식물 상세 뒤로가기, 사용자별 데이터 분리를 우선 검증한다.
아래 항목은 이번 빌드에 추가로 넣지 않고 베타 테스트 결과와 함께 순서대로 다룬다.

## 우선순위 높음

1. **앱 전체 다국어 마무리**
   - 카탈로그 데이터는 3개 언어를 지원하지만 일부 버튼, 안내문, 오류 메시지에는
     아직 한국어 고정 문구가 남아 있다.
   - 영어·독일어 기기에서 홈, 등록, 수정, 상세, 설정의 전체 흐름을 점검한다.

2. **식물 상세 관리 정보 활용**
   - 카탈로그에 있는 빛, 습도, 적정 온도, 독성/반려동물 주의 정보를 상세 화면에서
     이해하기 쉽게 보여준다.
   - 현재 물주기 중심 화면을 유지하면서 정보가 과밀해지지 않는 구성을 먼저 정한다.

3. **식물 등록 검색창의 실제 기기 사용성**
   - 키보드를 열고 검색·스크롤·선택할 때 결과 목록이 가려지거나 스크롤이 충돌하지
     않는지 iPhone과 Android에서 확인한다.
   - 문제가 확인되면 화면 전체를 하나의 가상 목록 구조로 정리한다.

4. **계정 복구 선택지 보강**
   - 익명 사용자는 앱 삭제나 기기 변경 시 기존 데이터에 다시 접근할 수 없다는 안내를
     계속 명확히 보여준다.
   - Apple 로그인을 쓸 수 없는 Android 사용자를 위한 계정 연결/복구 방식은 별도로
     결정한다.

## 우선순위 중간

5. **식물별 설명 품질 개선**
   - 초기 80종 중 공통 관리 설명을 공유하는 식물이 있으므로, 인기 식물부터 종별
     특징과 주의점을 한국어·영어·독일어로 다듬는다.

6. **실기기 화면 및 접근성 점검**
   - Dynamic Island/노치 여백, 작은 Android 화면, 큰 글자 설정, 색 대비,
     터치 영역, 4열 식물 그리드를 확인한다.

7. **오프라인·네트워크 오류 대응**
   - 느린 연결이나 일시적인 Supabase 오류에서 재시도 안내와 저장 상태가 명확한지
     점검한다.

8. **회귀 테스트 자동화**
   - 식물 등록/검색, 물주기와 실행 취소, 수정, 언어 전환, 익명 사용자 데이터 분리를
     자동 테스트 대상으로 추가한다.

## 베타 테스트에서 먼저 확인할 흐름

- 새 설치 후 기기 언어에 맞는 초기 언어가 선택되는지
- 인기 식물 5종과 검색 결과에서 원하는 식물을 등록할 수 있는지
- 한글명·영문명·학명·독일어 이름 검색이 자연스러운지
- 서로 다른 기기/사용자가 상대방 식물을 조회하거나 수정할 수 없는지
- 기존 사용자의 식물과 물주기 기록이 그대로 유지되는지
- 식물 상세의 뒤로가기와 마지막 물 준 날짜 직접 수정이 정상 동작하는지
